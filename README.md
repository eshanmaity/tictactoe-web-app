# 🎮 Tic Tac Toe Web Application

A responsive and interactive **Tic Tac Toe Web Application** built using **HTML, CSS, and JavaScript**. The game provides a simple two-player experience with real-time turn tracking, automatic win and draw detection, and an easy restart option.

## 🚀 Features

* ❌⭕ **Two-Player Gameplay** — Play locally with another player.
* 🔄 **Turn Indicator** — Clearly displays which player's turn it is.
* 🏆 **Win Detection** — Automatically detects winning combinations.
* 🤝 **Draw Detection** — Identifies when the board is full without a winner.
* 🔁 **Restart Game** — Start a new game instantly after a match.
* 📱 **Responsive Design** — Designed to work across desktop, tablet, and mobile screens.
* 🎨 **Interactive UI** — Clean and intuitive game interface with responsive interactions.

## 🛠️ Technologies Used

* **HTML5** — Provides the structure of the game interface.
* **CSS3** — Handles layout, styling, responsiveness, and visual presentation.
* **JavaScript (ES6+)** — Implements game logic, player turns, win/draw detection, and interactions.

## 🎮 How to Play

1. Player 1 starts the game using **X**.
2. Player 2 plays using **O**.
3. Players take turns selecting an empty cell.
4. The first player to form a line of three matching symbols wins.
5. If all cells are filled without a winner, the game ends in a draw.
6. Use the **Restart** button to begin a new game.
